# Auto Social Media Poster

## 🌟 Concept
Automating repetitive social media tasks using browser simulation.

## 🧠 Logic & Workflow
1. **Headless Browser Setup**
2. **Element Location**
3. **Automated Typing**
4. **Post Scheduling**

## 🤝 Helping Hand (Pro Tips)
- Add `time.sleep()` with random intervals to avoid being detected as a bot.

## ⚡ GPU & CUDA
This project is mostly CPU-bound and does not require a high-end GPU.

## 🚀 Getting Started
1. Install dependencies: `pip install -r requirements.txt` 
2. Run: `python main.py`
